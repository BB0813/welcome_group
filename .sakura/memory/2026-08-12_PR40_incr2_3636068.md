## 2. 发现的模式

### 代码模式
```
多层 Fallback 策略
├── 路径 1: bot.send_group_msg()     ← 绕过框架
├── 路径 2: event.send()            ← 框架兼容
└── 路径 3: logger.warning()        ← 静默降级
```

这种模式常见于框架升级场景，但理想情况下应该有版本检测而非运行时探测。

### 架构观察
- **Bot 对象获取方式**：`getattr(event, 'bot', None)` — 依赖运行时注入，耦合于框架实现
- **参数传递**：`message_list` 作为 list 直接传递，框架负责序列化
