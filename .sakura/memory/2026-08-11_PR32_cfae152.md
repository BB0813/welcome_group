## 三、规范完善建议

### 1. 新增审查规则：全局 API 调用扫描
当涉及框架 API 变更时，quick 策略应扩展扫描范围：
```
触发条件：修复涉及 event.send() / message.send() 等核心 API
要求：grep 全项目同类调用，检查是否存在相同问题
```

### 2. 新增规范：AstrBot 兼容性声明
类似 Issue 分析规范中的"依赖第三方 API"要求：
```markdown
修复涉及 AstrBot 框架 API：
- 已验证框架版本：X.X.X
- API 签名变更：已确认/待确认
- 兼容性风险：影响版本范围 X.X.X ~ X.X.X
```

### 3. 代码风格规范补充
在项目规范中明确：
```python
# 统一使用 f-string，避免 + 拼接
f"错误信息: {e}"  # ✅
"错误信息: " + str(e)  # ❌
```
